{%- comment -%} Sends a visitor to their language the first time they land on an unprefixed (default-language) page. Inlined in before the stylesheet so it runs before first paint. Four rules keep this loop-free by construction: 1. Only unprefixed pages redirect. A /nb/ page never does. 2. An explicit choice in localStorage always wins — including "en", which is what makes "I clicked English" stick on a Norwegian browser. 3. Auto-detection runs at most once per tab, and uses location.replace() so the Back button leaves the site instead of bouncing. 4. ?lang=xx counts as an explicit choice and is remembered. Crawlers that don't run JS see the plain default-language page, which is what the canonical and hreflang tags advertise — no cloaking. {%- endcomment -%} {%- include i18n.html -%} {%- comment -%} Only languages this page exists in go into ALT, so a page that sets `translated: [en]` can never redirect to a URL that would 404. {%- endcomment -%} {%- assign alt_langs = page.translated | default: site.languages -%} {%- capture alt_urls -%} { {% for l in alt_langs %}{% capture u %}{% include lang_url.html path=ref lang=l %}{% endcapture %}{{ l | jsonify }}: {{ u | jsonify }}{% unless forloop.last %}, {% endunless %}{% endfor %} } {%- endcapture -%}
